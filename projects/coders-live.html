FRONTEND · BANGLA LEARNING UI

Coders Live.

A Bangla learning-platform interface connecting courses, blog content, instructor pages, and account screens.

PROJECT TYPE
Multi-page interface project
TOOLKIT
HTML · Tailwind CSS · JavaScript · DaisyUI
Open demo ↗ (opens in a new tab)Source code ↗ (opens in a new tab)

The question.

How can a learning interface make room for both discovering courses and exploring the people behind them?

Coders Live is a multi-page Bangla interface. Its repository contains the home page, blog and blog-detail pages, instructor pages, account screens, and a payment-related screen.

The implementation.

  • Built Bangla-language page layouts using HTML, Tailwind CSS, and DaisyUI.
  • Included mobile-menu controls, course sections, and separate blog and instructor views.
  • Organized account and payment-related screens into their own page folders.

Design decisions.

Using lang="bn" and Bengali typography places the language at the center of the interface. Separate HTML pages make the different browsing paths explicit.

Scope & next steps.

The case study covers the visible frontend and page structure. Account and payment screens are interface work, not evidence of an implemented authentication service or payment processing backend.
