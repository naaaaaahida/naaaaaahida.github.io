Customer Churn Prediction.

A Telco churn workflow connecting feature preparation and XGBoost with an interactive customer risk form.

PROJECT TYPE
Notebook and Streamlit application
TOOLKIT
Python · XGBoost · SMOTE · Streamlit · Plotly
Source code (opens in a new tab)

The question.

What can customer behaviour and account choices tell us about retention risk?

The project uses the Telco Customer Churn dataset. The notebook prepares categorical and numeric inputs, performs a stratified 80/20 split, applies SMOTE to the training data, and fits an XGBoost classifier.

The implementation.

  • Prepared 19 input features, including account tenure, contract type, services, and charges.
  • Balanced the training split with SMOTE before fitting XGBoost and saving the model and encoders with Joblib.
  • Built a Streamlit form that displays a class prediction, probability chart, and a risk tier from the model output.

Design decisions.

The notebook and application share saved model/encoder artefacts. That separates the training workflow from the customer-facing prediction interface.

Scope & next steps.

The saved notebook reports 76.79% test accuracy on its holdout split. This is a recorded repository result, not an independently rerun benchmark. The confusion matrix also shows missed churn cases; accuracy alone is not a complete measure of retention usefulness.
