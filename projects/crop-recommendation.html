Crop Recommendation System.

A seven-input crop recommendation interface, with supporting soil-health and Power BI artefacts.

PROJECT TYPE
Prediction interface and BI artefacts
TOOLKIT
Python · Scikit-learn · Streamlit · Power BI
Source code (opens in a new tab)

The question.

What can soil and environmental conditions tell us about a suitable crop?

The Streamlit interface collects nitrogen, phosphorus, potassium, temperature, humidity, soil pH, and rainfall. It passes these seven measurements to a saved classification model.

The implementation.

  • Exposed soil and weather inputs through sliders and number fields.
  • Loaded a saved model with Joblib, then displayed the predicted crop and its model probability.
  • Included soil-pH feedback in the app and Power BI/data artefacts in the repository.

Design decisions.

The interface keeps the feature order explicit when creating the model input array. A separate BI artefact supports reporting alongside the prediction app.

Scope & next steps.

The displayed probability is a model output, not a guarantee of crop yield or local suitability. No field validation or measured yield improvement is claimed here.
